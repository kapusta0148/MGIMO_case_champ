# Сценарий демонстрации (видео до 5 минут)

Записывать с телефона или в Chrome с шириной 360–390 px. Данные «живые»: сервер каждый день сам переносит ближайшее занятие, поэтому конкретные предметы и время на записи будут свои.

| Время | Что показать | Что сказать |
|---|---|---|
| 0:00–0:20 | Экран входа, пометка «конкурсный прототип» | Проблема: расписание, оценки, справки и сообщения деканата разбросаны. Мы собрали их в один экран. |
| 0:20–1:00 | Вход `student1` → «Сегодня»: талон следующей пары, строка переноса, дедлайн, заявка | За несколько секунд понятно, куда идти, что изменилось и что горит. |
| 1:00–1:40 | Колокольчик → уведомление о переносе → «Открыть занятие в расписании» | Уведомление ведёт прямо к занятию. Старое время зачёркнуто, новое выделено — в уведомлении и в расписании одно и то же. |
| 1:40–2:40 | «Заявки» → «Новая» → «Справка об обучении». Нажать «Отправить» с пустым полем, потом заполнить | Форма объясняет, что не так. После отправки видно номер и статус. |
| 2:40–3:10 | Обновить страницу, выйти, открыть ту же ссылку, войти снова | Заявка хранится на сервере, а не в браузере. Без входа личные страницы не открываются. |
| 3:10–3:30 | «План»: свободные окна, «Почему так?», «Добавить в мои задачи» | Планировщик раскладывает подготовку к дедлайнам по окнам между парами и объясняет каждое предложение. Без нажатия ничего не меняется. |
| 3:30–3:50 | «Оценки»: экзамен, зачёт, «ожидается», зона внимания | Видно, где оценка, где зачёт, а где результат ещё впереди. |
| 3:50–4:30 | Выйти, войти `student2`, открыть ссылку на заявку первого студента | Другой студент — другие данные. Чужая заявка по прямой ссылке не открывается. |
| 4:10–4:40 | (если хватает времени) Вход `dean` → «Заявки» → заявка студента → «Взять в работу» → «Одобрить» с комментарием; затем у студента — новый статус и уведомление | Деканат обрабатывает заявки в своём кабинете, студент сразу видит результат. |
| 4:40–5:00 | Профиль → тема «День»; компьютерная версия | Тёмная тема по умолчанию и светлая для солнца. Как мы использовали ИИ — в описании процесса. |

Перед записью: проверить, что прототип открыт по опубликованной ссылке, а не на localhost, и в кадр не попадают пароли.
