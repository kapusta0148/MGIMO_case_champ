# Решения

Кто принял решение указано явно. «Claude Code» означает техническое решение ИИ-агента в рамках полномочий из `START_PROMPT_CLAUDE_CODE.md`.

| Дата | Решение | Кто | Почему |
|---|---|---|---|
| 15.11 | Flask + React/TypeScript/Tailwind + PostgreSQL | команда (до старта, в `CLAUDE.md`) | — |
| 15.11 | Один адрес для страниц и `/api`: Flask раздаёт собранный интерфейс | Claude Code | cookie-сессия и CSRF без CORS; одна HTTPS-ссылка для жюри |
| 15.11 | Серверные сессии в таблице `auth_sessions`, в cookie только случайный идентификатор | Claude Code | выход действительно отзывает доступ, даже если cookie сохранили |
| 15.11 | Argon2id для паролей | Claude Code | рекомендация OWASP |
| 15.11 | Ограничение попыток входа хранится в PostgreSQL, без Redis | Claude Code | работает при нескольких процессах Gunicorn и не требует ещё одного сервиса на дешёвом VPS |
| 15.11 | Время в базе — UTC, показ — Europe/Moscow | Claude Code | расписание вуза привязано к Москве независимо от пояса телефона |
| 15.11 | Занятие хранит текущие и исходные значения; уведомление о переносе ссылается на занятие и при показе берёт текст из него | Claude Code | уведомление и расписание не могут разойтись |
| 15.11 | Чужая заявка отвечает 404, а не 403 | Claude Code | нельзя даже узнать, что заявка с таким номером существует |
| 15.11 | Баллы 0–100, буква, оценка и «зачтено» вычисляются из балла по одной шкале | Claude Code | одинаковые цифры на всех экранах; шкала помечена как демонстрационная |
| 15.11 | Раз в сутки сервер сам делает свежий перенос ближайшего занятия и напоминания о дедлайнах | Claude Code | жюри откроет прототип в любой день до 28.11, и сценарий с переносом должен работать |
| 15.11 | Пароли демо-аккаунтов генерируются при `flask seed` и пишутся в `instance/` вне Git | Claude Code | требование не хранить пароли в публичном коде |
| 17.11 | Дизайн-концепция **A «Ночной рейс»** | **Дима** | выбор из трёх вариантов в `docs/design/concepts.html` |
| 17.11 | Тёмная тема по умолчанию + светлая «День» в профиле, выбор хранится в браузере | Claude Code | риск концепции A — читаемость на солнце; тема — настройка устройства, не учебные данные |
| 17.11 | Шрифты Onest и Unbounded раздаются с нашего сервера (Fontsource, OFL 1.1) | Claude Code | без обращений к Google Fonts: работает из России и проходит политику безопасности `font-src 'self'` |
| 17.11 | Окно поиска демо-переноса — 3 дня вместо 2 | Claude Code | в субботу вечером ближайшие пары в понедельник; иначе на «Сегодня» не было бы переноса |
| 17.11 | Коммиты делает Дима, Claude Code только готовит изменения | **Дима** | — |
| 17.11 | Playwright запускается в установленном Google Chrome | Claude Code | не нужно скачивать отдельный браузер |
