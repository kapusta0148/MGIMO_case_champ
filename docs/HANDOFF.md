## Готово и проверено

- Кабинет студента в дизайне A «Ночной рейс»: вход, «Сегодня», расписание, оценки и сессия, заявки, уведомления, профиль, светлая и тёмная темы.
- Размещение в Yandex Cloud: HTTPS (Let's Encrypt), Gunicorn, PostgreSQL 16, брандмауэр, копия базы дважды в сутки, ежедневное обновление демо-переноса.
- Кабинет сотрудников: деканат (очередь заявок, решения, перенос и отмена занятий, объявления, сводка), преподаватель (баллы своих курсов с журналом), администратор (аккаунты, журнал действий).
- Планировщик «План на неделю»: свободные окна, раскладка подготовки к дедлайнам, предупреждения, личные задачи; предложения принимаются только кнопкой.
- Проверки: локально pytest **194 passed**, e2e **21 passed**; на сайте e2e **21 passed** (360, 390, 1280 px). Подробно — [TEST_REPORT.md](TEST_REPORT.md).

## Не готово

1. Проверка людьми: телефон через мобильную сеть, без VPN, из России.
2. Вложения к заявкам и регистрация демо-студентов (остаток P1).
3. Языковая модель в планировщике (нужны провайдер и согласование бюджета), Web Push.
4. Документ «Описание процесса создания» (PDF со скриншотами) — обязателен для сдачи. Публичный репозиторий для жюри.
5. Коммиты — делает Дима. Заглушка PyCharm и локальная конфигурация Claude Code удалены из проекта.

## Обслуживание сервера

| Действие | Команда (из корня репозитория) |
|---|---|
| Выложить новую версию | `bash ops/deploy/deploy.sh` |
| Проверить сайт сквозными тестами и вернуть демо-данные в исходное состояние | `bash ops/deploy/check_production.sh` |
| Зайти на сервер | `ssh -i ~/.ssh/mgimo_campus_deploy deploy@153.51.170.126` |
| Логи приложения и Caddy | `sudo journalctl -u campus -u caddy -n 100` |
| Копии базы | `/var/backups/campus/` (7 дней, на том же диске) |

Секреты сервера (пароль базы, `SECRET_KEY`) — только в `/etc/campus/campus.env` на сервере.
