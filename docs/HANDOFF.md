# MGIMO Campus — состояние на 17.11.2026

Конкурсный прототип, неофициальный сервис, все данные вымышлены.

## Готово и проверено локально

- Кабинет студента в дизайне **A «Ночной рейс»**: вход, «Сегодня», расписание (день, неделя, дедлайны), оценки и сессия, заявки (5 типов, история, комментарии), уведомления, объявления, профиль, тема «Ночь»/«День», страница 404.
- Сервер: Flask + PostgreSQL, серверные сессии, Argon2id, CSRF, ограничение попыток входа, проверка владельца на каждом запросе.
- Проверки: pytest **132 passed**, Playwright **12 passed** (360, 390, 1280 px), ruff и сборка без ошибок. Подробно — [TEST_REPORT.md](TEST_REPORT.md).

## Не готово

1. **Размещение** — нет сервера, нет ссылки для команды и жюри. Это главный риск: по плану ссылка нужна была уже 17.11.
2. Кабинет сотрудников (деканат, преподаватель, администратор), вложения, регистрация демо-студентов — P1.
3. Календарь, AI Planner, Web Push — P2.
4. Проверка людьми на настоящих телефонах.
5. Коммиты — делает Дима. `main.py` (заглушка PyCharm) лучше удалить перед первым коммитом. Папку `.claude/` (настройки запуска для Claude Code) можно не коммитить.

## Запуск

См. [README.md](../README.md). Коротко: `docker compose up -d` → в `backend/` `flask db upgrade && flask seed` → в `frontend/` `npm install && npm run build` → `flask run --port 5001`. Пароли демо-аккаунтов — `backend/instance/demo_credentials.json`.

Если `npm install` падает с `EACCES` в `~/.npm`: в кеше npm есть папки, принадлежащие root. Исправить: `sudo chown -R $(whoami) ~/.npm`, либо `npm install --cache /tmp/npm-cache`.
