# MGIMO Campus: пакет для Claude Code

**Статус:** техническое задание, не готовый сайт.

## Что внутри

- `CLAUDE.md` — исходный контекст команды (сохранён) + подтверждённые решения четырёх раундов. Это основной файл инструкций в корне репозитория.
- `MGIMO_CAMPUS_SPEC_v1.md` — требования, роли, маршруты, база данных, API, безопасность, этапы и тесты.
- `START_PROMPT_CLAUDE_CODE.md` — мастер-промпт запуска в Claude Code.

## Запуск работы

1. Создай новую пустую папку для исходного кода проекта, например `mgimo-campus`.
2. Перенеси в неё все файлы из этого пакета (не в подпапку).
3. Инициализируй Git и открой папку в Claude Code.
4. Скопируй содержимое раздела «Стартовый мастер-промпт» из `START_PROMPT_CLAUDE_CODE.md` в новый диалог Claude Code (или попроси Claude Code прочитать файл и выполнить его).
5. Согласуй одну из трёх визуальных концепций, которые Claude обязан предложить. Без согласия на оплату он не должен приобретать хостинг или AI API.
6. Проверь P0: два аккаунта, перенос занятия, оценки, заявка сохраняется, чужую заявку нельзя открыть, мобильная ширина 360 px.

## Важное

- Это конкурсный **неофициальный** прототип на вымышленных данных.
- Не публикуй реальные пароли, токены, ключи ИИ и персональные данные в репозитории.
- Внутренний дедлайн команды — 21.11.2026, официальный — 22.11.2026 23:59 МСК, доступность до 28.11.2026.
- Отдельно веди журнал ИИ-разработки со скриншотами, реальными тестами и ошибками.
